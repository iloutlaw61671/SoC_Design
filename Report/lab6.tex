\chapter{Peripheral Firmware and Debugging}

\section{Firmware and ILA}

The Lab 6 snapshot configures the LED controller for 1\,kHz at 100\% duty
cycle, reads AXI GPIO channel~1, and copies the value to the LED enable
register. The System ILA probes the display APB bus, the LED AHB-Lite bus,
and the instruction and data local memory buses.
